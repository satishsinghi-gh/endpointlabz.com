Security and privacy in EasyNotes

Applies to EasyNotes 1.1 for Windows 11Publisher Satish Singhi, trading as EndpointLabzUpdated November 2026

EasyNotes is a privacy-first productivity app. Your notes stay on your PC, there is no account to create, and the app sends no usage data. This article explains how EasyNotes stores and protects your notes, how the optional features that connect to AI tools and to the internet work, and the controls available to you and to your organisation.

1Design principles

  • Privacy first. Your notes are stored on your PC, in a folder you choose - and, if you wish, synced to your own cloud drive.
  • No account, no subscription, no telemetry. EasyNotes does not ask who you are and does not collect usage data.
  • Powerful and practical AI features - off by default. Features that open your notes to other software - MCP, the Agent panel and the session clipboard - are off by default.
  • Least-privilege MCP. You decide the level of access each AI tool gets, through a separate secure token generated for every AI tool that connects to EasyNotes over MCP. You also write the rules your AI tools must follow when they work with EasyNotes.
  • Nothing installed behind your back. EasyNotes never downloads or installs AI tools or any of their components. You install and sign in to the AI tools you choose.
  • Safe by default. When a setting or a security check cannot be confirmed, EasyNotes chooses the more restrictive option.

2How EasyNotes stores your notes

Your notes are stored in your notes folder, which you choose during setup and can change later in Settings › Storage.

  • Open, readable formats. Each page, sheet and code page is a separate file: pages and code pages are stored as JSON text, and sheets as CSV files that open in Excel. Pictures and attachments are kept as the original files, next to the pages that use them.
  • Your structure is recoverable. An index file records your topics and their order. Each page also keeps a small recovery record, so EasyNotes can rebuild the structure if the index file is ever damaged or lost.
  • Saves cannot leave a half-written file. EasyNotes writes each change to a temporary file, flushes it to disk, and then replaces the previous version in a single step. A crash or power cut leaves either the old version or the new one, never a mix.
  • Safety copies stay on this PC. The previous version of each saved file is kept as a safety copy in the app data folder on this PC - not in your notes folder - so it is never synced and never included in a backup.
  • Deleted items are recoverable. Deleted topics and pages move to a trash folder inside your notes folder.
  • Sync folders are supported. If your notes folder is in OneDrive, Google Drive or Dropbox, EasyNotes detects the conflict copies these services create and merges them instead of overwriting your changes.
  • Older versions do not overwrite newer data. If a notes folder was last saved by a newer version of EasyNotes, an older version opens it read-only.
  • App settings stay on this PC. Settings, reminders and the app's diagnostic log are stored in your user profile (%LOCALAPPDATA%\EasyNotes). The diagnostic log is never sent anywhere.
Note

EasyNotes does not encrypt your notes. They are protected by your Windows user account, and by BitLocker device encryption if it is turned on. We recommend turning on BitLocker on any PC that holds sensitive notes. If you keep your notes folder in a cloud sync folder, that service's own security and retention policies apply to it.

3Backups

EasyNotes backs up your notes automatically. You can change the schedule and the location in Settings › Backup.

SettingDefaultOptions
Backup scheduleEvery dayEvery 2, 4 or 8 hours, or every 1 to 7 days
Keep backups for30 days1 to 90 days
Backup locationDocuments\EasyNotes_Backup (in OneDrive Documents if OneDrive is set up)Any folder you choose
  • Every backup is verified. EasyNotes saves your open notes, writes the backup as a ZIP file under a temporary name, then reopens it and checks every file in it before giving it its final name. An existing backup is never overwritten.
  • Clean-up is limited to EasyNotes backups. When old backups expire, EasyNotes deletes only files named EasyNotes_Backup_*.zip in the backup folder.
  • Restoring never destroys data. A restore unpacks the backup into a separate folder and then swaps it in. Your current notes are kept in a folder named <notes folder>_before-restore_<date>.
  • You can turn backups off if you don't need them.

4Session clipboard

The session clipboard remembers what you copy while EasyNotes is running, so nothing you copy during a call or while researching is lost. It is off by default; turn it on in Settings › Session Clipboard.

  • It keeps up to 300 items: text, links, files and pictures.
  • Items are stored only on this PC, in your user profile. They are never written to your notes folder, never synced and never included in a backup.
  • Items are deleted when EasyNotes closes. If EasyNotes closes unexpectedly, the leftovers are deleted the next time it starts.
  • Content that other apps mark as private, such as passwords copied from a password manager, is not recorded.

5AI tools and MCP

About MCP

The Model Context Protocol (MCP) is an open standard that lets AI tools work with other apps.

When you turn MCP on, EasyNotes acts as an MCP server, and supported AI tools on your PC connect to it as clients. A connected tool can use only the EasyNotes functions that its access token allows (see MCP functions below).

Supported AI tools

AI toolHow it connectsNotes

Codex app (ChatGPT desktop / Codex)AI tools on this PC sets it up for you, or Copy configChatGPT desktop chats may not offer MCP tools yet - Codex does

Gemini and Grok work in the Agent panel only; they cannot connect to EasyNotes over MCP.

Before you connect an AI tool

  1. Install the AI tool yourself, from its publisher or the Microsoft Store. EasyNotes never downloads or installs AI tools or their components. Whether installing needs administrator rights depends on that tool's own installer.
  2. Open the AI tool once and sign in with your account. Some tools create their settings folder only on first run.
  3. Turn on MCP in Settings › MCP, then connect the tool as described below.

Connect an AI tool

You can connect an AI tool in two ways, both in Settings › MCP:

  • AI tools on this PC. EasyNotes shows which supported AI tools are installed for your Windows account and can add EasyNotes to a tool's MCP settings for you, with a token created for that tool.
  • Copy config. Copy the configuration and add it to the AI tool's own MCP settings yourself. Use this for tools EasyNotes cannot set up automatically, such as Perplexity.

When EasyNotes sets up a tool for you:

  • It checks only when you ask. EasyNotes looks for installed AI tools only when you open the MCP settings or select Re-detect - never in the background. It does not keep a record of the software on your PC.
  • It writes only to a tool that is installed. If a tool is not found, nothing is written.
  • It changes only its own entry. EasyNotes adds, replaces or removes only the easynotes entry in the tool's configuration file and leaves everything else in the file as it was. If EasyNotes cannot read the file with certainty, it does not change it and tells you why.
  • It backs up first. Before any change, EasyNotes saves a copy of the tool's configuration file in its own folder, readable only by your Windows account. The last five copies for each tool are kept.
  • It replaces tokens safely. When EasyNotes sets up a tool again, it creates a new token and revokes the one it replaces. Token values are never shown or logged.

Your organisation can turn off automatic setup with a policy; the Copy config option remains available.

How access is controlled

  • Off by default. MCP is off until you turn it on in Settings › MCP.
  • Local only. EasyNotes listens only on your own PC (127.0.0.1, port 47391 by default). It cannot be reached from your network or from the internet, and it does not need administrator rights.
  • One access token per tool. Every request must include a valid token. Each AI tool gets its own token, with the permission scope you choose:
ScopeAllows
ReadThe read functions in the table below
WriteRead, plus the write functions

  • Your rules apply. In Settings › MCP you can write rules in plain language, such as which topics an AI tool must not read or change. Every connected tool receives these rules before it works with your notes, and can read them again at any time.
  • Requests from web pages are refused. EasyNotes rejects requests that come from a website, so a page you visit cannot use your browser to reach your notes.

How access tokens are protected

  • Strong tokens. Each token is a 256-bit random value generated by the Windows cryptographic random number generator.
  • Never stored by EasyNotes. EasyNotes stores only a SHA-256 fingerprint of each token, which cannot be turned back into the token. A token you create yourself is shown only once.
  • Copied privately. When you copy a token, EasyNotes marks it as private, so it is not saved in Windows clipboard history or synced to your other devices.
  • Kept off the command line. The configuration that EasyNotes provides passes the token to the AI tool as an environment variable, not as a command-line argument.
  • Revoked instantly. When you revoke a token in Settings › MCP, the tool that uses it loses access at once.
Important

Your AI tool keeps its token in its own configuration file on your PC, and the configuration backups EasyNotes makes contain earlier tokens. Anyone who can sign in to your Windows account can read these files. If you suspect a token has been exposed, revoke it and create a new one.

Transparency and audit

  • Every change an AI tool makes is recorded in the audit trail, and the bell notifies you. Audit trails for all activities inside EasyNotes can be viewed and searched in the Dashboard.
  • Every request, allowed or refused, is recorded in the audit log, which you can view in Settings › MCP.
  • Every AI change is also a step in the page's undo history, so you can step it back.
  • When an AI tool imports a file from your PC, EasyNotes reads the file directly. The file's content does not pass through the AI tool.

6Agent panel

The Agent panel lets you work with your AI agent in a side panel, next to your notes. EasyNotes supports these agents:

AgentWebsiteSign-in optionsCan also work with your notes over MCP
Claude (Anthropic)claude.aiEmail, Google or AppleYes - with the Claude desktop app
ChatGPT and Codex (OpenAI)chatgpt.comEmail, Google, Apple or MicrosoftYes - with the Codex app
Perplexityperplexity.aiEmail, Google or AppleYes - with the Perplexity app
Gemini (Google)gemini.google.comGoogle accountNo - Agent panel only
Grok (xAI)grok.comEmail, Google, Apple or XNo - Agent panel only

One agent is active at a time, and the panel header shows which one. You can switch agents from the header or the panel menu. Each agent has its own separate browser profile, and nothing is carried from one agent to another when you switch.

Gemini and Grok - Agent panel only

A Gemini or Grok chat in the panel cannot hand work to an app on your PC, so these agents cannot read or write your notes directly. Use Send page, Send selection and Insert reply instead. You do not need the Gemini or Grok desktop or command-line tools.

The panel is off until you set it up. Your organisation can turn it off, or allow only some agents, with a policy.

How the Agent panel works

  • An input to your AI tools, from your notes. The Agent panel is how you hand content from your notes to your AI agent. For Claude, ChatGPT/Codex and Perplexity, when the agent's desktop app is also connected to EasyNotes over MCP, the same agent can write its output back into your notes - see Let the agent work with your notes below.
  • A built-in, separate browser. The panel uses Microsoft Edge WebView2, the browser engine of Microsoft Edge that is built into Windows 11 and kept up to date by Microsoft. It runs as an isolated profile, separate from Edge, Chrome or any other browser you use: it shares no sign-ins, cookies or saved passwords with them, browser extensions are turned off, and it is not signed in with your Windows account.
  • You sign in on the agent's own website. You sign in on the agent's own sign-in page. EasyNotes never sees your password, your account details or your chats, and it does not run any code in the agent's website or read from it.
  • You decide what is shared. Your notes reach the agent only when you choose Send page or Send selection. EasyNotes copies the content to the clipboard as a private item and pastes it into the agent's message box; you review it and send it yourself. Pictures are passed as temporary files, which are deleted after the next send, when the panel closes and when EasyNotes exits.
  • You decide what comes back. Insert reply adds text you copied in the panel to your page or to a new page.

With Stay signed in, you can also choose Keep only the sign-in cookie. Each time EasyNotes starts, it deletes everything in the panel's browser profile except the agent's sign-in cookie, including the cache, history and cookies from other sites.

Windows Hello (optional added security for Agent panel access)

You can require Windows Hello - your PIN, face or fingerprint - before the Agent panel opens. Choose when EasyNotes asks:

  • At the first open after EasyNotes starts
  • After Windows is locked
  • After the panel has not been used for a set time
  • Every time the panel opens

If you cancel Windows Hello, the panel stays closed. Windows Hello protects the Agent panel only; it never blocks access to your notes.

EasyNotes also protects an open panel:

  • The panel closes when Windows locks, or when it has not been used for the time you set. The next time it opens, Windows Hello is required again.
  • If Windows Hello stops being available - for example, it is turned off, or you connect over Remote Desktop - EasyNotes removes the saved sign-in and asks you to set up the panel again.

Let the agent work with your notes

On its own, the Agent panel is a website and cannot read or change your notes. Together with MCP, it completes the loop: you send content from your notes to the agent in the panel, and the same agent writes its output back into EasyNotes over MCP. This is available for Claude, ChatGPT/Codex and Perplexity - not for Gemini or Grok, which are limited to the Agent panel. It requires all of the following:

  1. The agent's desktop app is installed on the same PC - the Claude desktop app, the Codex app or the Perplexity app (see Before you connect an AI tool above).
  2. The desktop app is signed in with the same account that you use in the Agent panel.
  3. EasyNotes is connected to the desktop app over MCP, with an access token (see Connect an AI tool above).
  4. The conversation you use in the agent is set to use this computer.

Some AI tools offer local MCP connections only on certain plans; check the tool's own documentation.

The agent can then do only what its token allows, under your rules, and every change is recorded in the notification bell and the audit trail. To stop the agent from working with your notes, revoke its token or turn off MCP. Send page and Insert reply continue to work without MCP.

7Browser security

EasyNotes uses Microsoft Edge WebView2 in two places, and locks each one down for its purpose.

Agent panel

  • Loads only the active agent's website and its sign-in pages. Other links open in your default browser.
  • Developer tools, password saving, form autofill and browser extensions are turned off by design.
  • The agent's website has no connection to EasyNotes and cannot read or change your notes.
  • Permission requests are refused, except the browser's own prompts for microphone access (for dictation) and for reading the clipboard.

Page editor

  • The editor that displays your pages runs entirely inside EasyNotes and makes no network connections. A strict content security policy blocks every outside connection, and navigation to any other address is blocked.
  • Developer tools are turned off.

8Links in topics and pages

  • Web links open in your default browser.
  • Links to folders open in File Explorer.
  • Links to files show the file selected in File Explorer. EasyNotes never runs or opens the file itself.
  • Other types of links are refused.

10Controls for organisations

Administrators can manage EasyNotes with Group Policy or MDM (for example Microsoft Intune), using the EasyNotes administrative templates (ADMX). The templates ship inside EasyNotes: Settings › Policy Templates › Extract templates…, or EasyNotes.exe --export-policy-templates "<folder>". Policies are read from HKLM\SOFTWARE\Policies\EasyNotes first, then from HKCU. With policies, you can:

  • Turn MCP on or off, set its rules and port, and turn off automatic setup of AI tools.
  • Turn the session clipboard and backups on or off, and set the backup location, schedule and retention.
  • Set the notes folder.
  • Turn off the Agent panel, choose which agents are allowed and which is the default, and require its sign-in option, automatic sign-out, Keep only the sign-in cookie and Windows Hello.

A setting that is set by policy is locked in the app and shows that it is managed by your organisation. For deployment steps and the full list of policies, see Deploy EasyNotes in your organisation.

1Reporting a problem

A report with these five things is usually solved in one round of email:

  1. The EasyNotes version. Open Settings (the gear in the header) › About – the version is under the title.
  2. Your Windows version. Press Win+R, type winver, press Enter and copy the version and build shown.
  3. What you did, what happened and what you expected – step by step, with the page or feature involved.
  4. A screenshot if the problem is something you can see.
  5. The app log. Settings › Storage › App Data › Open, then attach EasyNotes.log (and Backup.log for backup problems, or use Settings › Backup › Open backup log). The logs record what the app did, not what your notes say.
Your notes are never needed

Please do not send your notes folder. If a specific page triggers the problem, a copy of that page with the private parts removed is enough.

2Frequently asked questions

The page editor is blank, or says the WebView2 Runtime is missing

EasyNotes draws its page editor with the Microsoft Edge WebView2 Runtime, which is part of Windows 11 and of Windows 10 installations that have Microsoft Edge. If it has been removed, install the Evergreen WebView2 Runtime from Microsoft (search for “WebView2 Runtime download” on microsoft.com), then start EasyNotes again. No other download is ever needed.

Where are my notes?

In the notes folder you chose during setup – Settings › Storage shows it and opens it. Each page is a file of its own, so the folder can be backed up, copied or synced like any other. The User Data section of the guide describes every file.

How do I use EasyNotes on two PCs?

Keep the notes folder in a location that OneDrive, Google Drive or Dropbox syncs, then point the second PC at the same folder during setup (“Your EasyNotes data is already here”). Changes from both PCs are merged. See Using EasyNotes on two PCs.

How do I restore a backup?

Settings › Backup › Restore from backup… checks the archive first, keeps your current notes folder under a new name (nothing is deleted) and reloads the restored notes. Backups are on by default; the Backup section explains the folder, schedule and retention.

Will uninstalling delete my notes?

No. Uninstalling removes the app, its settings and logs. Your notes folder and your backup archives stay exactly where they are.

Reminders do not pop up

Reminders are shown by EasyNotes itself, so it must be running – minimised to the tray is fine. Settings › Windows › Start at sign-in keeps it running after you sign in. Overdue and upcoming reminders are always listed under the To-do button in the header.

How do I connect an AI tool?

Settings › MCP › turn MCP on, create a token for the tool, and paste the configuration block it shows into the tool. The MCP for AI tools section walks through Claude Desktop, Claude Code, Cursor and any other MCP client. MCP is off by default, listens only on your own PC, and every change a tool makes is logged.

A setting says “Managed by your organisation”

Your PC is managed by an organisation whose administrators set that value through Group Policy or Intune. Only they can change it; the For IT administrators note lists what can be managed.

Is EasyNotes really free? What about updates?

Yes – free, with no account, no subscription and no in-app purchases. Updates arrive through the Microsoft Store like any other Store app; EasyNotes never checks for updates or contacts the internet by itself. See the privacy policy.

4Security reports

If you believe you have found a security weakness in EasyNotes or this website, please email hello@endpointlabz.com with “Security” in the subject and enough detail to reproduce it, and give us a reasonable time to fix it before describing it publicly. Reports are acknowledged, and you will be credited in the release notes if you wish.
